# Mystic Tech Visual Language

Use este design system quando o cliente pedir um redesign com identidade premium, visual "tech"/cinemático ou quando o brief mencionar Mystic Tech.

## Aplicação no redesign
- Use como base de direção de arte, mas preserve a marca do cliente.
- Não repita a mesma hierarquia/hero entre clientes; adapte os padrões abaixo ao contexto real.

## Elevação e profundidade
- Use glassmorphism com backdrop-filter blur alto e bordas fantasma.
- Prefira translucidez + brilho a sombras pesadas.
- Z-axis: base escura → painéis translúcidos → elementos interativos luminosos.

## Componentes
- Botão primário: amber sólido, texto preto, pill, glow no hover.
- Botão secundário: vidro + borda amber, texto branco/amber.
- Inputs: fundo escuro semitransparente, borda inferior ou sutil, foco com glow amber.
- Chips/tags: uppercase, fonte Geist, bordas fortes, fundo leve.
- Navegação: topo fixo, blur crescente no scroll.
